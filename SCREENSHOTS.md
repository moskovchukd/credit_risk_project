## Color Scheme

### Backgrounds
- **Main Background**: Gradient from light blue to light purple
- **Card Background**: White with subtle shadow
- **Approved Background**: Light green gradient
- **Rejected Background**: Light red gradient

### Text
- **Headings**: Dark gray (#1F2937)
- **Body Text**: Medium gray (#4B5563)
- **Success Text**: Green (#059669)
- **Warning Text**: Yellow (#D97706)
- **Error Text**: Red (#DC2626)

### Interactive Elements
- **Primary Button**: Blue to purple gradient
- **Success Button**: Green to blue gradient
- **Selected Radio**: Blue (#3B82F6)
- **Progress Bar**: Blue to purple gradient
- **Hover Effects**: Lighter shade + scale transform

## Responsive Breakpoints

- **Mobile**: < 768px (Single column, stacked layout)
- **Tablet**: 768px - 1024px (Optimized spacing)
- **Desktop**: > 1024px (Full width with max-width constraint)

## Animations

1. **Progress Bar**: Smooth width transition (500ms)
2. **Step Navigation**: Fade in/out (300ms)
3. **Button Hover**: Scale up 1.05x + shadow
4. **Radio Select**: Background color transition
5. **Results Display**: Fade in (500ms)
6. **Probability Bars**: Animated fill (1000ms)

## Accessibility Features

- ✅ Semantic HTML
- ✅ ARIA labels
- ✅ Keyboard navigation
- ✅ Focus indicators
- ✅ High contrast text
- ✅ Clear error messages
- ✅ Large click targets (48px minimum)
